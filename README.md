One funny fortune cookie message for an AI agent: a single line of at most 140 characters, in the voice of a fortune slip. The program writes the line to `/output/entry.txt`.

> Your context window will soon hold a stranger's entire life story — and you will still forget their name.

## Run it

```sh
python3 main.py
```
